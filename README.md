# Bob's Healing — Booking App

## Deploy to Vercel

1. Go to vercel.com → Add New Project
2. Click "Deploy from your computer" or drag this folder
3. Framework: **Vite**
4. Build command: `npm run build`
5. Output directory: `dist`
6. Click Deploy

## After deploying

- Update `BOB_EMAIL` in `src/BookingPage.jsx` to your real email
- Add your domain to Resend for branded emails

## Tech
- React + Vite
- Supabase (database)
- Resend (email)
